## EMBEDDED CIRCUITS
- **Arduino Light Sync**
  Audio-reactive lighting system built with MOSFETs, audio amplifiers, and an Arduino UNO.

- **DEPTH Distance Analyzer**
  Real-time distance change analysis system using an ultrasonic distance sensor.

- **Dino Run Automation**
  Automated game controller for Chrome Dino Run using LDR light sensors and servo motors.

- **LED Valentine Heart**
  Animated heart-shaped LED circuit synchronized using a 555 timer chip.

- **Battery-Powered Smart Weather Station**
  Reads environmental sensors and transmits data over Wi-Fi or Bluetooth before entering deep sleep mode to maximize battery lifespan.

- **Bare-Metal Microchip Programming**
  Programs an ARM or AVR microcontroller directly using C and register manipulation rather than high-level framework abstraction libraries.

- **Multi-Tasking RTOS Controller**
  Implements a real-time operating system to run multiple concurrent tasks—such as sensor polling, display driving, and USB communications—without blocking the central CPU loop.

- **CAN Bus Vehicle & Industrial Reader**
  Interfaces with an OBD-II port or industrial CAN network to capture live engine telemetry and render it on a localized display screen.

- **Custom USB Macropad**
  Designs a custom PCB in KiCad featuring mechanical keys and a USB-C interface programmed to operate natively as an HID shortcut device.

- **Closed-Loop Motor Controller**
  Uses encoder feedback and PID algorithms to dynamically regulate DC motor speed and position under changing mechanical loads.

- **Real-Time Digital Audio Filter**
  Processes live audio signals through a microcontroller, applying digital signal processing algorithms to filter out unwanted noise frequencies.

- **Long-Range LoRa Wireless Tracker**
  Transmits low-power sensor data over long distances via sub-GHz radio protocols without relying on Wi-Fi or cellular networks.

- **Industrial RS-485 / Modbus Node**
  Builds a noise-isolated sensor module using RS-485 differential signaling to reliably communicate with factory automation hardware.

- **Custom Li-Ion Battery Management System (BMS)**
  Designs a PCB to safely regulate lithium battery charging, monitor accurate state-of-charge, and provide overcurrent/thermal protection cutoff.

- **Over-The-Air (OTA) Bootloader**
  Develops a custom bootloader enabling a device to wirelessly update its own application firmware over Wi-Fi or Bluetooth.
